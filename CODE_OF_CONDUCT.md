# Code of conduct

## Our standard

Project discussions should be constructive, specific, and welcoming. Contributors are expected to:

- discuss code and behavior rather than personal characteristics;
- respect different experience levels, languages, and viewpoints;
- give actionable review feedback and accept corrections professionally;
- avoid harassment, threats, discriminatory language, and publishing private information;
- keep bug reports and pull requests relevant to the project.

## Enforcement

Maintainers may edit, hide, or remove contributions that violate these standards and may restrict
participation for repeated or severe violations. Report conduct issues privately through the
maintainer's GitHub profile rather than escalating them in a public thread.

This code of conduct applies in repository issues, pull requests, reviews, and other spaces where a
person is representing the QueHun project.
