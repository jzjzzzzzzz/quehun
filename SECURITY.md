# Security policy

## Supported version

Security fixes are applied to the current `main` branch. This repository does not currently
maintain parallel release branches.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving arbitrary code execution, unsafe file
handling, credential exposure, or bypass of guarded-click checks. Use the repository's
[private security advisory form](https://github.com/jzjzzzzzzz/quehun/security/advisories/new).

Include the affected commit, platform, reproduction steps, impact, and a minimal proof of concept.
Reports are acknowledged as soon as they are reviewed, and remediation is coordinated privately
before public disclosure.

Ordinary recognition errors and incorrect discard advice are regular bugs and should use the bug
report template.
